# Playwright Automation

Playwright automation is deferred for the current milestone.

Reason: no browser-based Employee Management functionality, UI screen, or implemented user workflow exists in the approved Project Bootstrap milestone. The milestone validates Symfony/PHP project bootstrap artifacts only.

Playwright tests may be introduced in later milestones when implemented browser functionality exists, such as:

- Login/session timeout UI behavior.
- PIM advanced search screen.
- Add employee duplicate validation.
- Employee audit history view.
- Role permission configuration screen.
- Bulk employee import screen.
