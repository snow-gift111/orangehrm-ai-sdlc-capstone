# Known Limitations

The following limitations remain after the current Project Bootstrap milestone:

- No feature-layer Employee Management functionality is implemented.
- No controllers, APIs, services, entities, repositories, migrations, or DTOs for RBAC, audit history, search, duplicate detection, authentication security, or bulk import are implemented yet.
- No database schema changes are included.
- No user-facing UI workflows are implemented.
- No browser automation is available because there is no implemented UI flow to test.
- API testing is not applicable because no APIs are implemented.
- Business configuration values for password policy, lockout threshold, session timeout, duplicate rules, import template, audit retention, and delete/deactivate behavior remain future implementation inputs.
